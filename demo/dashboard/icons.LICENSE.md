# Service icons

Icons for services that Font Awesome does not cover. Their SVG markup is
embedded in `icons.js` (`SVG_ICONS`), with `fill`/`stroke` set to
`currentColor`, so they take the color of the surrounding text.

| Icon | Service | Source | License |
|------|---------|--------|---------|
| `ipfs` | IPFS | [Simple Icons](https://simpleicons.org) 13.21.0 | CC0 1.0 |
| `wireguard` | WireGuard | [Simple Icons](https://simpleicons.org) 13.21.0 | CC0 1.0 |
| `xmpp` | XMPP | [Simple Icons](https://simpleicons.org) 13.21.0 | CC0 1.0 |
| `qaul` | qaul | [qaul.net](https://github.com/qaul/qaul.net) `qaul_ui/assets/logo/logo.svg`, background removed and cropped | logo of the qaul.net project |
| `gopher` | Gopher | [Iconoven](https://github.com/iconoven) `beaver`, via Iconify | MIT |

The logos are trademarks of their respective owners and are used here only
to identify the service.
